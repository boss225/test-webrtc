# VibeRoom

> Connect. Collaborate. Create.

VibeRoom is a modern real-time video conferencing and chat platform built with Next.js, WebRTC, and Supabase.

## Features

✨ Real-time video calls with WebRTC
💬 Instant messaging
🎥 Screen sharing
🔐 Secure authentication
👥 Room management
🚫 Blacklist & moderation tools
📱 Responsive design

## Tech Stack

- **Frontend**: Next.js 15, React, TypeScript, Tailwind CSS
- **Backend**: Next.js API Routes, Supabase
- **Real-time**: WebRTC, Server-Sent Events (SSE)
- **Authentication**: JWT, bcrypt
- **Database**: PostgreSQL (Supabase)

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables (see `.env.example`)
4. Run development server: `npm run dev`
5. Open http://localhost:3000
